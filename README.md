# MiteProxy

基于 [mitmproxy](https://mitmproxy.org/) + PySide6 的类 Fiddler 抓包 / Mock 桌面工具。  
macOS 与 Windows 双平台支持。

![status](https://img.shields.io/badge/status-alpha-orange)



![license](https://img.shields.io/badge/license-MIT-green)

> 📖 **新手请先看[使用教程](TUTORIAL.md)**：5 分钟上手、抓 HTTPS / 手机抓包、Mock、  
> API 调试、WebSocket、弱网模拟等场景化步骤，以及常见问题排查。

## 功能

- **抓包**：HTTP/HTTPS 流量捕获，请求/响应详情（headers + body，文本/十六进制）
  - **自动接管系统代理**：启动即抓，不用手动改网络设置；退出自动还原（Fiddler/Charles 同款体验）
  - 列表列：`# / 方法 / 主机 / 服务器 IP / 路径 / 状态 / 大小 / 耗时 / 标记`，悬停显示完整 URL 与服务端 IP
  - 服务器 IP 取上游真实对端；CONNECT 隧道与 mock 短路（未连上游）显示 `-`
  - **表头点击即排序**：数值列按数值排（`1.3 MB` 不会排在 `812 B` 前面）、文本列按字符串排；`#` 列恒为抓包到达序号，排序只改显示顺序
  - **顺序**：工具栏切「到达顺序（新在底部）」/「新的在顶部」，配置持久化
  - **自动滚动**（默认开）：新会话到达时跟着滚到最新一条；**你手动翻到别处时不会来抢滚动条**，按其他列排序时也不动
  - **多选**：`Ctrl` / `Shift` 点选、`Ctrl+A` 全选，可批量复制与导出；状态栏显示 `已选 N 条`
  - 保存数量：工具栏可选 `100 / 200 / 500 / 1000 / 2000 / 3000 / 5000` 条（上限 5000），超出丢弃最旧，配置持久化
  - mock 命中的会话整行着色（浅绿底 + 绿字）并显示 `MOCK` 标记，扫一眼就能区分真实响应与造数据
  - **会话备注**：右键「标记/备注…」给任意会话写备注（mitmproxy 原生 `comment` 字段，与 MOCK/REPLAY 徽标互不覆盖），列表「标记」列与详情面板顶部显示，随会话保存/恢复不丢失
  - **请求耗时分析**（对齐 Fiddler Statistics）：详情面板「耗时」页把每条请求拆成 连接（含 DNS）/ TLS / 发送 / 等待（TTFB）/ 接收 五段，画占比条；mock 与恢复会话同样有数据（分段缺锚点时明说原因，不拿 0 伪装"很快"）
- **移动端支持**：内置证书下载服务，手机装 CA 后抓 App 流量；下载页每个局域网地址配一枚**二维码**，手机扫码直达不用手输 IP
- **Mock 规则**：命中规则的请求直接返回预设响应，**不发给真实服务器**
  - 四种匹配：精确 / 包含 / 通配符（`*` 不含 `/`，`**` 任意）/ 正则
  - **按请求方法过滤**（任意 / GET / POST / … 下拉一选，不用像 Fiddler 那样拼正则）
  - 响应内容：内联文本 **或** 本地文件（请求时读取，改文件即生效）  
    **或 重定向到其他 URL**（规则级 Map Remote：请求改发到目标地址并返回真实上游响应，  
    支持 `$1` 正则捕获组替换做路径改写；目标指向本代理自身会被拒绝防止死循环）
  - 任意状态码（100~~599）+ 自定义 headers + 模拟延迟（0~~60s）
  - 规则按顺序匹配、可启用/禁用、热生效
  - **命中计数**：规则页「命中」列实时显示每条规则被命中的次数与最近命中时间（内存计数，不污染可分享的 rules.json）
  - **规则搜索**：规则页工具栏「搜索:」按 URL / 名称实时过滤（大小写不敏感），与「只显示启用」叠加；过滤空结果有空态说明，不会面对空表以为规则丢了
- **请求重放**：`Ctrl+R` 或右键「重放请求」原样重发；「编辑并重放」可改  
  method/URL/headers/body 后重发。重放产生新会话（带 REPLAY 徽标），原会话不动
- **重放并对比**：右键「重放并对比…」（可先编辑请求），重放响应到达后**自动弹出对比窗口**——  
  左原响应、右新响应，底部差异报告：JSON 走**键级 diff**（`$.user.name: "tom" → "jerry"`），  
  非 JSON 走行级 diff，二进制只报同/不同；可一键复制差异
- **Fiddler 规则导入**：
  - `.farx` 规则包（AutoResponder / Rules 导出）完整导入
  - `CustomRules.js` 启发式导入（典型 mock 模式，导入前可预览、可勾选）
- **body 结构化视图**（对齐 Fiddler 的 JSON / WebForm / ImageView inspector）：请求与响应各有  
  `自动 / 原文 / JSON / 树 / 表单 / 图片 / 十六进制 / SSE` 一排切换按钮（Fiddler 风格，非下拉），默认「自动」按 content-type 挑最合适的
  - **SSE（Server-Sent Events）**：`text/event-stream` 自动识别并切到 SSE 视图，把逐条 `event / data / id / retry` 事件拆开渲染，便于看流式推送
  - **树**：折叠树视图，三列 **键 | 类型 | 值**——类型列直接标 `object` / `array` / `string` / `number` / `boolean` / `null`，结构一眼看清；右上角「层级」菜单可**按层展开**（第 1/2/3 层或全部展开/收起），大 JSON 逐层钻取不会一步铺开几千行（子节点超过 100 个的分支保持折叠，可手动再展开）
  - **JSON**：缩进 2 空格 + 语法着色（key / 字符串 / 数字 / 布尔分色，深浅主题各一套）；中文原样显示不转义成 `\uXXXX`；key 顺序保持服务端返回顺序，便于和线上逐行对照
  - **WebForm**：`application/x-www-form-urlencoded` 自动展开成 key / value 表，**URL 已解码**（中文、空格、特殊字符直接可读），空值字段 `flag=` 也保留
  - **图片**：`image/*`（含 SVG）直接预览，显示格式 / 像素尺寸 / 体积，可切「适应窗口 / 25% / 50% / 100% / 200%」
  - **十六进制**：文本解不出来时自动给，偏移 / 十六进制 / ASCII 三栏
  - **压缩内容自动解压**：gzip / deflate / br / zstd 按 `Content-Encoding` 解开后展示，并注明「已解压 gzip：线上 12.3KB → 89.1KB」；mitmproxy 解不开时按魔数兜底再试一次
  - **换行开关**：默认开。单行超过 64KB 时会临时关闭并说明原因（超长行换行是超线性开销，300KB 单行要 1.2s）
  - 解析失败**一律回落原文并说明原因**，不会把 body 显示没了
  - 手动切换后保持（换会话不回弹）；`Ctrl+F` 搜索高亮在 JSON 与表单表格里同样生效
- **WebSocket 抓包**：捕获 WS 连接与**逐条消息**
  - 列表显示 `WS N` 徽标与已捕获消息数，悬停给出连接状态
  - 详情面板多一个「WebSocket」页：消息表（序号 / 时间 / 方向 / 类型 / 长度 / 内容预览），点一条看它的 payload（同样支持 JSON 着色 / 表单 / 图片 / 十六进制）
  - 关闭时显示关闭码与原因，耗时按连接存活时长算
  - **消息随会话文件保存/恢复**（最多 2000 条或保存预算耗尽即止，超限注明 `truncated`）
- **API 调试**（工具页第 4 子页）：构建请求（方法 / URL / headers / body）直发并就地看响应  
  （状态 / 耗时 / 响应头 / body 六模式渲染）；`Ctrl+Return` 发送；右键流量列表  
  「发送到 API 调试」把选中请求完整带入改参数重发；默认跳过证书校验、3xx 不跟随
- **工具页**（对齐 Fiddler TextWizard 与 json.cn，`Ctrl+Shift+T` / `Ctrl+Shift+J` / `Ctrl+Shift+D`）：
  - **编码转换**：27 种转换——URL / Base64 / Hex / HTML 实体 / Unicode / JSON 字符串转义，Gzip 压缩与解压，JWT 解码，时间戳与日期互转，MD5 / SHA-1 / SHA-256；失败给原因（红字），不崩也不静默给空结果
  - **JSON 工具**：格式化（缩进档位可调）+ 压缩 + 校验，右侧可切**格式化文本 / 树形 / JSONPath 结果**三种视图；树形**懒加载**——展开才构建子节点，大 JSON 不卡
  - **JSON 比对**：左右两段 JSON 实时出**键级差异表**（路径 / 类型 / 旧值 / 新值，增删改分色），可交换左右、一键复制差异；和「重放并对比」共用同一个 diff 引擎
  - **JSON 解析错误给到行列**：显示「第几行第几列 + 出错的那一行 + `^` 指针 + 常见原因提示」（尾逗号、单引号、NaN…），点「跳到出错位置」直接跳到输入框对应行列
  - **JSONPath 提取**：支持 `$.a.b` / `$['a']` / `$[0]` / `$[-1]` / `$[1:3]` / `$[*]` / `$..name` 递归下降 / `$[?(@.price > 10 && @.x =~ 'A|B')]` 过滤，以及聚合函数 `length()` / `min()` / `max()`（`$.l[*].price.max()` 取所有 price 的极大值），结果列出路径与值
  - 继承 body 视图的全部大内容闸门：深嵌套不崩、大 JSON 先完整解析只截断渲染、超长单行临时不换行并说明
  - **FIX 解析**：粘贴报文（SOH / `|` / `\u0001` 转义均可，多条消息每条一个 tab，校验不过的标红可跳转）→ 四列字段树（标签 / 字段 / 值 / 注释），字段名中英对照、类型标注、枚举释义，重复组可折叠；BodyLength / CheckSum 按字节校验
  - **合作方私有字段**：FIX 工具栏「字典」→ `⋯` →「导入字典文件…」，把对方协议文档里的字段表做成 CSV/TSV 或 JSON 导入（菜单里可一键复制模板；Word/PDF 的表格直接贴进 Excel 另存 CSV 就行，中文表头、标题行、`-` 占位都认）；**同一 tag 以导入的字典为准**，内置通用字段照常可用，导入后自动切换、下次启动沿用；**改版后同名再导一次即覆盖**，不会多出副本
  - **可拖出为独立窗口**（新增）：工具页整体或单个子页（编码转换 / JSON / 比对 / API 调试 / FIX）都能拖成**独立非模态**浮窗——按住导航按钮或子页标签往外拖即可，拖出后主窗口照常抓包；浮窗里的确认/输入/文件框只锁这一个浮窗，不会把主窗口一起锁住。关掉浮窗即收回原位（拖出期间主窗口留占位页，导航与 `Ctrl+1…7` 对应关系不错位）。Mock 规则 / 网络模拟 / 脚本 / 日志 / 统计页同样可拖出；**详情面板**也能整体拖出（拖走后流量列表占满主窗口，收回按原分割比例还原），或把「请求」「响应」两个页签分别拖成独立窗口（内容照样跟着选中的会话刷新）
- **流量过滤**：域名黑名单/白名单 + 隐藏 CONNECT / Image
- **流量搜索**：`Ctrl+F`，可按 URL / Headers / Body 范围搜索，命中高亮、`Enter` 跳转
- **列显隐与自定义列**：表头右键勾选显示/隐藏列，`内容类型 / 开始时刻 / 备注` 三个可选列默认隐藏，显隐状态按列 key 随设置持久化
- **多套过滤预设**：工具栏过滤栏把当前条件存为命名预设，一键切换 / 删除；激活的预设随设置保存，启动自动套用
- **两条会话对比**：流量列表里**多选两条**右键「对比两条会话」，并排看方法 / URL / 状态 / headers 差异，body 走键级 diff（JSON）或行级 diff（文本），二进制只报同/不同——不用先重放就能比线上与本地
- **Raw 视图**：请求/响应详情各有一个「原始」页签，显示**完整 HTTP 报文**（请求行/状态行 + headers + body，Fiddler Raw 同款），一键复制全文
- **断点调试**：命中断点规则的会话**挂起**，弹编辑器改 method/URL/状态码/headers/body 后再放行或中止（Fiddler 断点同款；`Flow.resume()` 走事件循环线程安全恢复，挂起期间不阻塞代理）
- **批量操作**：多选后批量重放、批量删除选中会话（`Del`）
- **统计页**：总览卡片（总数/错误率/平均与 P95 耗时/上下行流量/请求速率）+ 按域名/状态码/方法分布 + 慢请求 Top N（双击跳回对应会话）+ 时间直方图；与 MCP 的 `get_stats` 同一套聚合口径
- **MCP 接口**：应用内起 HTTP 服务，把抓包记录暴露给 AI 客户端（Claude Desktop 等），三个**只读**工具：`get_recent_flows` / `get_flow_detail` / `get_stats`；默认只听本机，可配局域网监听。**写操作**（默认关，需手动开）：`add_mock_rule` / `replay_flow` / `set_breakpoint`——没开时工具列表不暴露、调用直接拒绝，默认只读安全
- **会话保存与恢复**（对齐 Fiddler 的 Save All Sessions / Load Sessions）：
  - `Ctrl+S` 保存为 `.jsonl`（一行一条会话，流式追加、半截文件也能读）
  - `Ctrl+O` 打开恢复；恢复出来的会话**仍是活会话**——能看详情、能导出、**能重放**
  - **退出自动快照**（默认开，文件菜单可关）：下次启动询问是否恢复，选过之后就归档，不会每次弹
  - 大 body 有预算（单条 512KB / 整包 512MB），超预算只存元数据并告知，不会因为一条大 body 拖垮保存
- **网络模拟**（两个能力互相独立，改动即时落盘 + 即时推给运行中的代理）：
  - **弱网限速**：档位 `2G / 3G / 4G / 弱网` 或自定义延迟与速率，用来复现 loading 态、超时、骨架屏。  
    语义是「固定延迟 + 按响应体大小折算的传输时间，在响应发回客户端前一次性等待」，**不是逐块限速**（行为可预测、可复现）
  - **域名映射到本地**：把线上域名转发到本机服务（`api.prod.com` → `127.0.0.1:8080`），用于「线上前端 + 本地后端」联调。  
    只替换 scheme + 域名 + 端口，路径与 query 原样保留；填一半的行会标红并提示会被跳过
  - **本地目录映射（Map Local）**：把某个前缀的请求整个换成本地目录里的文件（填「原域名」+「本地目录」，如 `/data` → `~/site/data`）。  
    只拦 `GET`/`HEAD`，目录请求试 `index.html`；文件缺失 / 过大一律**透传上游**不报错；防路径穿越与符号链接逃逸
- **复制与导出**（右键选中会话，对齐 Fiddler 的 Copy / Save；**单条与多选批量都支持**）：
  - `Ctrl+Shift+C` 复制为 cURL（另提供 Windows cmd 单行版，右键菜单可选）
  - `Ctrl+Shift+U` 仅复制 URL
  - `Ctrl+E` 导出：**HAR 1.2** / **原始 HTTP 报文**（请求+响应全文）/ **完整响应**（Headers+Body）/ **仅响应 Body**（二进制原样）
  - `Ctrl+Shift+E` 或右键「导出完整响应（Headers+Body）…」直接导出响应报文，省掉选格式那一步
  - 多选时菜单项标注 `（N 条）`，文件内逐条分段；「仅响应 Body」一个文件装不下多条，多选时会被拦住
- **深浅色主题**：默认**跟随系统**深浅模式（macOS / Windows 原生切换即时生效），
  菜单「外观」可强制**浅色**或**深色**；JSON 着色、mock 命中行、搜索高亮等
  语义色两套配色自动切换，选择会记住
- **设置页**（菜单「设置 → 偏好设置…」，`Ctrl+,`）：端口（代理/证书）、保存条数、自动滚动、
  列表顺序、Body 换行、系统代理接管、主题、语言、退出自动保存会话、启动检查更新——
  原先散落在工具栏和各菜单里的开关集中到一处，改完点「确定」即时生效并同步工具栏
- **双平台打包**：macOS `.app` / Windows zip（exe + 依赖文件夹，解压即用），构建脚本随项目提供

## 快速开始

### 直接使用打包版（推荐，免装 Python）

1. 到 [Releases](https://github.com/yakrsa/MiteProxy/releases) 下载 `MiteProxy-v1.12-macOS-arm64.zip`
2. 解压得到 `MiteProxy.app`，拖进「应用程序」
3. **首次运行：右键 → 打开**——产物是 ad-hoc 签名、未经 Apple 公证，直接双击会被
   Gatekeeper 拦下；右键打开一次后即可正常双击启动
4. 启动后代理**自动开启**（默认 `127.0.0.1:8888`，Fiddler 同款端口），且默认**自动接管系统代理**——
   不用手动改网络设置，浏览器的流量直接进列表（macOS 首次会请求一次管理员授权；
   停止代理或退出应用时自动还原你原来的设置）；数据文件都在 `~/.miteproxy/`
5. 抓 HTTPS 需装 CA 证书：应用内「证书」页有**局域网二维码**，手机扫码直达下载页
   （详见[使用教程](TUTORIAL.md)第 2 节）

> 当前 Release 产物为 **arm64**（Apple Silicon M1~M4）。Intel Mac 与 Windows 用户
> 请走下面的源码路线自行构建；Windows 版由 `build_windows.ps1` 产出
> `MiteProxy-v<版本>-windows-x64.zip`，解压得到 `MiteProxy` 文件夹，双击其中的
> `MiteProxy.exe` 直接使用（免安装）。

### 开发模式

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.main
```

启动后：

1. 应用**启动即自动开启代理**（默认 `127.0.0.1:8888`，Fiddler 同款端口，可改）；**开启抓包 = 自动接管系统代理，关闭 = 自动还原**，不用手动改网络设置；  
   工具栏按钮可随时停止/重启。若端口被占用，会弹窗提示并自动复位按钮状态。
2. 自动接管没开（或失败）时手动指：浏览器/系统代理指向 `127.0.0.1:8888`，或命令行 `curl -x 127.0.0.1:8888 http://example.com`
3. 「Mock 规则」页新增规则，命中即返回 mock

## body 视图

详情面板（请求/响应各有）的 body 区顶部是一排 Fiddler 式切换按钮：  
`自动 / 原文 / JSON / 表单 / 图片 / 十六进制`，旁边是「换行」开关。

**自动**按 content-type 挑：`application/json`（含 `vnd.api+json`、`ld+json` 等 `+json` 变体）→ JSON 视图；  
`application/x-www-form-urlencoded` → 表单表；`image/*` → 图片预览；文本解不出来 → 十六进制；其余走原文。  
没声明 content-type 或声明成 `text/*` 时，若内容确实是 JSON 也会被认出来。

| 模式   | 例                                                                       |
| ---- | ----------------------------------------------------------------------- |
| JSON | `{"user":{"name":"张三","age":18}}` → 缩进着色，中文原样                           |
| 表单   | `name=%E5%BC%A0%E4%B8%89&flag=` → 表格两行：`name / 张三`、`flag / （空）`         |
| 图片   | PNG / JPEG / GIF / WebP / SVG → 预览 + 缩放档位，提示显示 `PNG · 800×600 · 12.3KB` |
| 十六进制 | 二进制内容 → `00000000  00 01 02 …  ....`                                    |

> 解析失败时会**退回原文并在提示里写明原因**（如 `JSON 解析失败，已显示原文：Expecting ...`），  
> 内容绝不会丢。手动切过模式后会保持，换会话不回弹；`Ctrl+F` 的命中高亮在 JSON 与表单表格里照常生效。

**大内容不会把界面拖死**（阈值都是实测出来的）：

- JSON **先完整解析、只截断渲染结果**，所以几 MB 的响应照样能格式化（不会像早期版本那样先截断再解析、反而报"解析失败"）；  
  超过 4MB 就不做格式化、直接给原文并说明。
- 渲染文本超过 256KB 时**暂停语法着色**（着色按行走，2 万行约 260ms）——丢颜色，不丢流畅。
- **换行**对多行文本几乎免费，但对超长单行是超线性开销（300KB 单行要 1.2s）。  
  所以单行超过 64KB 时会临时不换行并说明；切到 JSON 视图（格式化后是多行）就又能换行了。

**压缩内容**：mitmproxy 已按 `Content-Encoding` 解压，这里补一句提示说明线上体积与解压后体积；  
万一它没解开（比如服务端谎报编码），会按魔数再兜底一次，都不行就明说"解压失败，显示的是原始压缩字节"。

## WebSocket

WS 会话在列表里带 `WS N` 徽标（N = 已捕获消息数），选中后详情面板多一个「WebSocket」页。

- 上半是消息表：`# / 时间 / 方向 / 类型 / 长度 / 内容预览`，蓝色为客户端发送、绿色为服务端接收；  
  消息是**增量追加**的，你停在底部时会跟着滚，翻到别处不打扰。
- 下半显示选中消息的 payload，复用同一套 body 视图（JSON / 表单 / 图片 / 十六进制都可用）。
- 连接关闭后显示关闭码与原因；耗时按**连接存活时长**算，不是握手那几十毫秒。
- **消息会随会话文件保存**（`Ctrl+S`）：恢复后消息表、payload、关闭码原样回来。  
  为防吵闹的连接把文件撑爆，最多保存 2000 条（或保存预算耗尽即止），超出的部分会在保存结果里注明。

> 两条已知限制：  
> ① 保存有上限——超过 2000 条或预算耗尽的 WS 连接只存前一部分并注明 `truncated`  
> （宁可少存，不能把整个会话文件撑爆）；  
> ② 客户端握手请求行必须是 `http://` 形式（RFC 6455 的规定，主流客户端都这么做）——  
> mitmproxy 会把 `ws://` 的绝对 URI 判成非法 scheme 并返回 400。

顶部「工具」标签下有三个子页。右键流量列表「在工具中打开 body」会把选中会话的 body

### 编码转换

左输入右输出，选一个转换即出结果；工具栏四个常用按钮（URL 编解码 / Base64 编解码）一步到位。  
「结果转为输入」把输出灌回输入框，方便连着解多层（例如 Base64 → Gzip → JSON）。

| 分组      | 转换                                                                                                                   |
| ------- | -------------------------------------------------------------------------------------------------------------------- |
| 编解码     | URL 编码 / 编码（表单）/ 解码 / 解码（表单）、Base64 编解码、Hex 编解码、HTML 实体编解码、Unicode 转义 / 反转义、JSON 字符串转义 / 反转义、Gzip 压缩 / 解压、Deflate 解压 |
| 格式 · 文本 | JWT 解码（拆 header/payload 并美化，带 exp 过期提示）、JSON 美化、JSON 压缩、时间戳 ↔ 日期、转大写 / 小写                                            |
| 哈希      | MD5、SHA-1、SHA-256                                                                                                    |

> 压缩类转换的输入输出都是**文本形态**：压缩结果以 Base64 给出（mtime 固定，同输入同结果），  
> 解压时 Base64 与 Hex 两种都试，并在提示里说明实际按哪种解的——避免「看起来能解、  
> 其实解的是另一种编码」这种误导。

### JSON 工具

左侧输入，右侧三种视图：**格式化文本**（缩进档位 2/4/8 可调，语法着色）、**树形**（展开/折叠）、  
**JSONPath 结果**。按钮：格式化 / 压缩 / 校验 / 复制结果 / 清空。

**解析失败时长这样**（对齐 json.cn，但信息更全）：

```
第 3 行第 12 列
  "b": [1, 2,
        ^
Expecting value
提示：这一行看着像少了右括号 ]
```


点「跳到出错位置」会跳到输入框对应行列并选中。严格模式下 `NaN` / `Infinity` 会被拒
（与 `JSON.parse` 一致），重复 key 会解析成功但给出提示。

**JSONPath** 输入框 + 「提取」按钮，结果表列出每条命中的路径与值：

| 写法 | 含义 |
|---|---|
| `$.store.book[0].title` | 逐层取字段 |
| `$['store']['book'][-1]` | 括号写法（key 可带特殊字符）、负下标 |
| `$.store.book[1:3].title` | 切片（不含右端） |
| `$.store.book[*].price` | 通配所有元素 |
| `$..price` | 递归下降：所有层级里叫 price 的字段 |
| `$.store.book[?(@.price > 10 && @.title =~ 'A|B')].title` | 过滤：`== != > >= < <= =~` + `&&` / `||` |
| `$.store.book[*].price.max()` | 聚合函数：`length()`（数组/对象/字符串取长度，多命中计条数）、`min()` / `max()`（取数字极值）——对整个结果集生效，所以 `$.l[*].p.max()` 取的是所有 p 的极大值 |

> 这是**轻量子集**：不做脚本表达式、step 切片——抓包调试里用得极少，
> 做进来只会让报错更难懂。递归下降用迭代实现（深嵌套不爆栈），命中数有上限（防 `$..*` 拖死界面）。
> 函数必须带括号（`.max()`），字段恰巧叫 `max` 的写法（`$.a.max`）不受影响。

### JSON 比对

左右两个输入框各贴一段 JSON，**实时出键级差异表**（220ms 防抖）：

| 列 | 说明 |
|---|---|
| 路径 | JSONPath 风格：`$.user.name`、`$.list[2]` |
| 类型 | 新增 / 删除 / 修改（分色） |
| 旧值 / 新值 | 修改时两侧都给；增删只给一侧 |

- 和「重放并对比」共用同一个 diff 引擎：JSON 重排不会全行飘红，**key 顺序变化不算差异**
- 某一侧不合法时给出行列 + `^` 指针，**输入框内容不动**（绝不因为你贴了半截 JSON 就清空）
- 「交换左右」一键对调（比对方向随之反转）；「复制差异」把文本报告写进剪贴板
- 差异表最多显示 500 行，超出在状态栏说明（diff 仍会算完）

## 网络模拟

「网络模拟」页两个能力互相独立，改动**即时落盘并立即推给运行中的代理**，状态栏会提示「已立即生效」还是「代理启动后生效」。

**弱网限速**：选档位（`2G / 3G / 4G / 弱网`）或直接改延迟与速率（会自动切到「自定义」）。

延迟按这条算：`固定延迟 + 响应体字节数 / (速率 kbps × 1024 / 8) × 1000`，上限 30 秒。

> 语义提醒：这不是逐块限速，而是**在响应发回客户端前一次性等待**折算出的总时间。
> 复现 loading 态 / 超时 / 骨架屏足够，而且行为可预测——同样的响应每次都慢同样的时间。

**域名映射到本地**：填「原域名」「目标 host:port」，例如

| 启用 | 原域名 | 目标 host:port |
|---|---|---|
| ☑ | `api.prod.com` | `127.0.0.1:8080` |

- 只替换 scheme + 域名 + 端口，**路径与 query 原样保留**（`https://api.prod.com/v1/u` → `http://127.0.0.1:8080/v1/u`）
- 目标不写 scheme 时默认 `http`（本地服务几乎都是 http），要 https 就写 `https://dev.local:9000`
- 原域名含 `* + ? [ ] ( ) { } | \ ^ $` 时按**正则**处理，否则按字面域名精确匹配（所以 `api.prod.com` 不会误伤 `apiXprodYcom`）
- 填了一半的行会**标红**并在下方提示「N 条填写不完整（已跳过）」

**本地目录映射（Map Local）**：目标列填**目录路径**（`./site`、`/Users/me/site`、`~\site`）即可，
与 host:port 写法自动区分：

| 启用 | 原域名 | 本地目录 |
|---|---|---|
| ☑ | `static.prod.com` | `~/site/static` |

- 只拦 `GET` / `HEAD`，查询串丢弃，目录请求试 `index.html`，content-type 按扩展名推断
- 文件缺失 / 超过 100MB / 读取出错 → **透传上游**（本地缺文件不该让页面白屏）
- 命中打 `LOCAL:文件名` 徽标；`..` 穿越与符号链接逃逸都有防护

## 重放并对比

右键流量列表「重放并对比…」：先弹编辑对话框（可改 method/URL/headers/body，也可直接确认），
重放响应到达后**自动弹出对比窗口**（非模态，可一直开着继续抓包）。

- 顶部概要：URL、原/新状态码与大小、判定结论（`完全一致` / `N 处差异（JSON 键级）` / `文本有差异` / `二进制内容不同`）
- 中部左右双栏：原响应 vs 新响应，headers + body 全量可见（复用详情面板同一套 body 视图）
- 底部差异报告：
  - 两边都是 JSON → **键级 diff**，`+ $.added = 5` / `- $.gone = true` / `~ $.user.name: "tom" → "jerry"`；
    整个 JSON 重排不会全行飘红，key 顺序变化不算差异
  - 否则 → **行级 diff**（`difflib`）
  - 二进制 → 只报相同/不同
  - body 一致但 headers 有差 → 列出增删改的 header
- 「复制差异」一键把报告写进剪贴板

> 已知限制：JSON 列表**按下标对齐**，中间插入元素会让后续元素整体偏移（这类场景行级 diff 更能看出版本变化）；
> 上游一直不响应时 20 秒后在状态栏提示等待超时，不会永久挂起。

## 会话保存与恢复

「文件」菜单 →「保存会话…」把当前列表存成 `.jsonl`，「打开会话…」恢复。

- 恢复出来的会话**仍是活会话**：能看详情、能导出、**能重放**
- 大 body 有预算（单条 512KB / 整包 512MB）：超预算的只存元数据并告知有多少条未存，绝不因为一条大 body 让整次保存失败
- 恢复条数超过工具栏「保存数量」时保留**最新的一段**，并告知丢了多少条
- **退出自动快照**默认开启：退出时把会话存到 `~/.miteproxy/last-session.jsonl`，下次启动询问是否恢复；无论选是选否都会归档，不会每次启动重复弹框

## Raw 视图

请求/响应详情页除「查看」外各有一个「原始」页签：显示**完整 HTTP 报文**——请求行/状态行
（含 HTTP 版本）、全部 headers、原始 body（Fiddler 的 Raw 同款）。body 超 64KB 时只渲染开头
并注明实际大小，可一键复制全文。双击流量列表某条弹出的详情窗同样有这两个页签。

## 断点调试

工具栏「断点」开关（状态即时生效，不用重启代理）：开启后，命中的会话在**请求发出前**
或**响应返回前**挂起（在「设置 → 流量列表 → 断点」里选阶段），弹出编辑器：

- 可改 method / URL，或改状态码 + headers + body（自动同步 `Content-Length`）
- 「继续放行」按改后的内容继续走；「中止」直接掐掉这条会话
- **关窗口 = 原样放行**——不会把会话永久挂死
- 重放产生的副本不拦（`is_replay`），避免打断「重放并对比」

> 实现上 `flow.intercept()` 只打标记，真正挂起由 mitmproxy 内核在钩子跑完后
> `await wait_for_resume()` 完成，所以断点排在最前也不影响 mock / 弱网先生效。

## 统计页

「统计」页把当前列表里的会话聚合成一张总览（数据在内存里现算，5000 条也是一次聚合的事）：

- **总览卡片**：总会话、错误率（4xx/5xx）、平均耗时、P95 耗时、下载总量、请求速率
- **按域名**：请求数 / 错误数 / 错误率 / 平均与最大耗时 / 下载量，按请求数降序
- **按状态码 / 按方法**：次数与占比，无响应的会话单列一行
- **慢请求 Top N**：按耗时降序，**双击跳回流量列表对应行**；URL 悬停看全文
- **时间直方图**：按请求开始时间等宽分桶（最多 48 桶），悬停看该桶的时间范围、条数与下载量

> 统计范围 = **当前列表中的会话**（删除过的不计入），不受顶部过滤栏影响；
> 耗时与列表「耗时」列同口径（含弱网延迟）。尚未返回响应的会话其耗时会持续增长，页面上有提示。

## MCP 接口（给 AI 客户端）

[MCP](https://modelcontextprotocol.io)（Model Context Protocol）让 AI 客户端直接读取
MiteProxy 抓到的包——不用再手工复制粘贴报文给 AI。服务**内嵌在应用里**（数据在跑着的
GUI 进程内存中，另起进程只能读落盘会话、拿不到实时流量），**默认关闭**。

### 开启与监听地址

1. 工具栏点「MCP」按钮（上次开着的话下次启动自动开），或「设置 → 流量列表 → MCP 接口」
2. 监听地址三档：`127.0.0.1`（默认，仅本机）/ `0.0.0.0`（全部网卡，局域网可达）/ 具体网卡 IP
3. 端口默认 `8899`，被占用时自动向上顺延（最多 20 个）；状态栏会显示实际地址

> **安全提醒**：抓包内容可能带 Cookie / Authorization 等鉴权头。绑 `0.0.0.0` 或网卡 IP 后，
> **局域网内任何设备都能读取完整抓包**——选对外地址时设置页会即时变红字警告，用完记得关。

### 客户端配置示例

```json
{
  "mcpServers": {
    "miteproxy": {
      "url": "http://127.0.0.1:8899/mcp"
    }
  }
}
```

### 三个工具

| 工具 | 作用 |
|---|---|
| `get_recent_flows` | 返回最近的抓包记录。可按 `url` / `param`（query 或 body）/ `header` / `method` / `status` 过滤，`limit` 默认 20、上限 200；body 默认只给 2000 字预览 |
| `get_flow_detail` | 按 `id` 取**单条完整报文**（全量 body，超过 2MB 才截断；二进制回落 base64 并注明编码）。支持 id 唯一前缀。找不到走 `isError`（工具执行错误），不是协议错误 |
| `get_stats` | 整体统计：总数、错误率、平均/P95/最大耗时、上下行流量，按域名/状态码/方法聚合，慢请求 Top N，时间分桶直方图。可选 `url` 关键字只统计命中的会话 |

典型用法：`get_recent_flows` 用关键字 + `limit` 缩小范围拿到 id → `get_flow_detail` 展开细节；
整体问题（"刚才哪些请求挂了"）直接问 `get_stats`。

另有两个便利 REST 端点（非 MCP 标准，调试用）：`GET /api/flows`、`GET /api/flows/<id>`、
`GET /api/stats?url=&top_n=`。

## 用户脚本（插件）

想扩展抓包逻辑又不想改源码？把 Python 脚本丢进 `~/.miteproxy/scripts/` 即可，写法对齐
mitmproxy 的 `-s script.py`：

- 两种写法都支持：**模块级函数**（`def request(flow): ...` / `def response(flow): ...`）或一个
  **`Addon` 类**（`class Addon: def response(self, flow): ...`）；
- 可选 `ctx` 第一参：`def response(ctx, flow)` 会收到一个含脚本名的 dict，方便在日志里区分是哪个脚本；
- 在「**脚本**」页里增删改、启停；保存后**热替换**，运行中不用重启代理；
- 弹窗里写代码带 **Python 语法高亮**（关键字 / 字符串 / 注释 / 数字 / `def`·`class` 名 / 装饰器 / 常用内置分别着色，三引号跨行不断层，随深浅主题切配色），保存前还会先做一遍语法检查，语法错的脚本落不了盘；
- 单个脚本写错只会被隔离（记日志、在状态列显示错误），**不会拖垮其他脚本和代理主流程**；
- 安全边界（如实说明，不假装沙箱）：脚本在**本进程内**运行，与主程序同等权限——能读抓包内容、
  改流量、动文件。**只把脚本目录交给可信的人**，应用能保证的只有「单个脚本报错被隔离」这一条。

脚本模板（「脚本」页「新建」即自带）：

```python
"""MiteProxy 用户脚本。

支持的钩子（任选其一）：
    def request(flow): ...
    def response(flow): ...
    def error(flow): ...

或写成类：
    class Addon:
        def response(self, flow): ...
"""
def response(flow):
    if flow.response and "json" in (flow.response.headers.get("content-type") or ""):
        flow.response.headers["x-my-script"] = "1"
```

## 已知限制

- WebSocket 只做**消息级**展示（mitmproxy 会先把分片帧重组），不做分片帧 / ping-pong 等控制帧；WS 会话不可重放；WS 消息已随会话文件保存（v1.11，最多 2000 条或保存预算耗尽即止，超限注明 `truncated`）
- 流量过滤与搜索只影响显示，不影响抓取
- body 超过 512KB 的会话，搜索仅索引前 512KB
- `CustomRules.js` 导入为启发式解析，不保证覆盖所有写法
- 未做代码签名/公证（需要时再购买证书）
- body 解码默认 UTF-8；声明了其他 charset 的按声明解码，均失败时显示十六进制
- 二进制请求 body 在 cURL 命令里以 `@payload.bin` 占位（导出文件里仍是原始字节）
- 「完整响应」「仅响应 Body」要求会话已有响应，否则弹提示而不落空文件
- **「仅响应 Body」一个文件只能装一条会话**，多选时会被拦住；其余格式都支持多选批量
- HAR `timings` 用 mitmproxy 时间戳拆分发送/等待/接收，不含 DNS/TLS 建连等更细分段
- 会话文件是**本项目自有**的 `.jsonl` 格式；不导入第三方会话格式（HAR / Fiddler `.saz`）
- 弱网模拟是「一次性等待折算时长」，不是真逐块限速（见上文「网络模拟」）
- 域名映射只做 Map Remote 式的前缀改写，不提供正向代理链 / 反向代理 / pac 脚本
- Map Local 只拦 `GET`/`HEAD`；本地文件缺失时透传上游而不是报错（有意为之，见上文）
- 重放并对比：JSON 列表差异**按下标对齐**（中间插入元素会整体偏移）；二进制 body 只报同/不同；
  上游无响应时等 20 秒后在状态栏提示超时
- JSONPath 是轻量子集：不支持脚本表达式与 step 切片，过滤只到字段级比较（聚合函数 length/min/max 已支持）
- API 调试直连目标服务器（不走抓包代理），响应不进流量列表；JSON 树重建时用户手动折叠的状态会复位（重新展开即可）
- 系统代理自动接管的 Windows 注册表路径未经实机回归（macOS 已真机验证）
- body 范围搜索在超大列表（数千条 × 大 body）下可能明显变慢（逐条解码无索引缓存）
